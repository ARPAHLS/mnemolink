| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The ARPA Hellenic Logical Systems security team takes the security of our open source software seriously.

If you discover a vulnerability or security risk within **MnemoLink** (such as prompt injection escape vectors, arbitrary code execution, or path traversal vulnerabilities in resolution engines):

1. **Do not open a public GitHub issue.**
2. Send a detailed report to `security@arpacorp.net`.
3. Include reproduction steps, environment details, and proof of concept if possible.

We will acknowledge receipt within 48 hours and work with you on a responsible disclosure timeline.
